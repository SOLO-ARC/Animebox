# AnimeBox — Download Landing Page

Official download landing page for AnimeBox Android App.

## Features

- **Fast Playback**: High speed streaming on mobile networks.
- **No Ads**: Clean, uninterrupted viewing experience.
- **Multi-Audio**: Japanese, English, and Hindi audio tracks.
- **AniList Integration**: Live trending anime posters and data.

## Development

Requires Node.js / Bun.

```sh
npm install
npm run dev
```

## Tech Stack

- TanStack Start & React Router
- React 19 & TypeScript
- Tailwind CSS
- TanStack Query
- Lucide Icons
